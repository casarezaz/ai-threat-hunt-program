## Hypothesis

The vector index has been modified outside the sanctioned ingestion path — by an unrecognized actor, via a text-rewrite API outside a re-ingestion window, or with chunk content that no longer matches the source document.

## Why this matters

This is the index-side counterpart to embedding poisoning (Paper 3). It bypasses the source system entirely. The signal is mismatch between the source and the index.

## Data sources

- Vector store admin / write logs (actor, source IP, action, chunk IDs)
- Approved ingestion-actor list
- Periodic source-vs-index drift comparison job

## Detection logic

See Paper 3 §RAG-004. Summary: alert on writes from non-sanctioned actors, on text-rewrite operations outside a re-ingestion window, and on hash drift between sampled chunks and the source document.

## Evidence to capture

- Actor identity, source IP, write action
- Chunk IDs and source document IDs affected
- Whether a re-ingestion job was running concurrently
- Hash diffs from drift sampling

## Suggested defense pairing

- C-RAG-2 (index-write freeze) on suspected active poisoning.
