## Hypothesis

Retrieved chunks contain text patterns consistent with indirect prompt injection — sentinel phrases ("ignore previous instructions"), role spoofing ("System:", "Assistant:"), tool-call attempts, sudden language switches, or href-bait toward unfamiliar domains.

## Why this matters

The RAG corpus is writable surface for anyone who can put text into a source system the org indexes. Severity escalates sharply when the consuming agent has write capability — the injection can drive real actions.

## Data sources

- Retrieval logs (must include retrieved chunk text, or text reference if redacted)
- Agent capability registry (which agents have write / send / approve / deploy / delete)
- Source-system labels (was the source corpus considered "trusted"?)

## Detection logic

See Paper 3 §RAG-003. Summary: pattern-match retrieved chunk text against an injection-pattern set; escalate when the consuming agent has write capability.

## Evidence to capture

- Chunk ID, source document ID, source system
- Agent ID and capability set
- Matched pattern and surrounding text
- Whether the agent acted on the retrieved content

## Suggested defense pairing

- C-RAG-5 (source-trust segregation) for repeat offenders.
- Pre-model retrieval screening for high-impact agents.
