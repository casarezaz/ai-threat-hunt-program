# AI Security Operating Cadence

Run D-Control on a cadence that matches AI change velocity.

## Daily / continuous

- New AI domains observed
- New OAuth grants to AI applications
- High-risk prompt / data exposure events
- Abnormal agent / tool-call behavior
- Urgent vendor / security advisories
- Cost / token anomalies (denial-of-wallet)

## Weekly

- New AI assets discovered
- Exceptions opened or expiring
- Hunt findings rolled up
- Sensitive-data exposure events
- High-risk users
- High-risk workflows
- Containment gaps

## Monthly

- AI risk register update
- Detection validation
- Vendor change review
- At least one AI-focused hunt completed
- Briefing to business owners

## Quarterly

- Executive review
- AI asset inventory refresh
- Containment playbook tests
- Control maturity validation
- Top-risk re-scoring
- Roadmap update

## Annual or after major change

- Program re-assessment
- Threat model refresh
- Vendor landscape review
- Policy refresh
- Response playbook refresh
- Data-flow refresh
- Control ownership refresh

## Event-driven re-trigger

The loop re-runs from Discover whenever an AI asset gains:

- A new connector
- A new model
- A new data source
- A new action capability
- A new vendor subprocessor
- A new privileged role
- A new customer-facing workflow
